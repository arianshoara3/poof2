# POOF2 — جعبه‌ابزار حرفه‌ای فارسی

یک سایت استاتیک، فارسی و راست‌چین، آفلاین‌محور — ۹۰۰ ابزار حرفه‌ای در یک سایت.

- **هدف:** ۹۰۰ ابزار، هر ابزار یک کامیت، هر کامیت یک ابزار کامل و تست‌شده.
- **نسخه:** شماره‌ی نسخه = تعداد ابزارها. ابزار ۱ می‌شود v1، ابزار ۹۰۰ می‌شود v900.
- **تکنولوژی:** HTML / CSS / JavaScript ساده، بدون بیلد، بدون سرور. انتشار با GitHub Pages.
- **ساختار:** هر ابزار در `tools/<slug>/` زندگی می‌کند و در `tools.json` ثبت می‌شود.

## دسته‌ها (۱۰ دسته × ۹۰ ابزار)

1. متن و نوشتن
2. PDF و فایل
3. عکس و تصویر
4. صدا و ویدیو
5. محاسبه‌گر و مالی
6. تبدیل‌کننده و واحدها
7. توسعه‌دهنده و کد
8. زبان
9. سلامت و بدن
10. کسب‌وکار و بهره‌وری

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید. نیازی به سرور نیست.

## افزودن ابزار جدید

1. پوشه‌ی `tools/<slug>/` را با `index.html` و `tool.js` بسازید.
2. ابزار را به `tools.json` اضافه کنید.
3. یک کامیت: `feat(tool-XXX): <نام ابزار>`

ساخته‌شده توسط Muse — به نام Muse، در `arianshoara3/poof2`.
